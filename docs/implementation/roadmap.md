# 模块实施路线图

## 依赖分析

括号中的依赖是**运行时协作依赖**（需要对方先有实现），不含对 core 的编译依赖。

```
erp  ← (无运行时依赖)
iot  ← (无运行时依赖)
plm  ← (无运行时依赖)
equip← (无运行时依赖)
scm  ← (无运行时依赖)
dms  ← (无运行时依赖)

lims ← plm(蓝图编码) + erp(物料编码)
wms  ← erp(物料主数据) + scm(采购订单)
mps  ← plm(产品工艺数据)

mes  ← plm(蓝图) + equip(设备) + wms(物料) + lims(配方)
aps  ← mps(生产计划) + mes(在制品) + equip(设备日历)

qms  ← mes(工序触发检验)
andon← mes(工序异常) + iot(设备报警) + qms(质量异常)
eam  ← equip(设备台账)

bi   ← 所有模块(只读消费)
web  ← 所有模块(API聚合)
test ← 所有模块(集成场景)
```

## 五阶段实施计划

### Phase 1：基础设施 —— 独立模块，可并行

| 模块 | 核心任务 | 完成标志 |
|------|---------|---------|
| **erp** | 物料主数据本地缓存 + 库存查询 + 事务回传队列 | 能从外部 ERP 同步物料编码到本地缓存 |
| **iot** | 设备连接管理 + 标签采集 + 时序数据存储 | 能从一台设备读取一个标签值 |
| **plm** | 工艺路线(Blueprint)版本管理 + BOM转化 + 工艺参数 | 能创建产品工艺路线并发布版本 |
| **equip** | 设备台账 + 设备状态 + OEE基础计算 | 能注册设备并查询状态 |
| **scm** | 供应商管理 + 采购订单 + 来料计划 | 能创建供应商和采购订单 |
| **dms** | 文档创建 + 审批流 + 审计追踪 | 能创建 SOP 文档并通过审批 |

> **并行度：6 个模块可同时开工，彼此零运行时依赖**

### Phase 2：设计层 —— 依赖 Phase 1 的部分输出

| 模块 | 依赖 | 核心任务 | 完成标志 |
|------|------|---------|---------|
| **lims** | plm, erp | 配方版本管理 + 称量任务 + 称量防错脚本 | 能创建配方并生成称量任务 |
| **wms** | erp, scm | 收货上架 + FIFO拣料 + 库存盘点 | 能收货入库并拣料到线边仓 |
| **mps** | plm | 生产计划创建 + 粗产能检查 | 能从销售订单生成周生产计划 |

> **并行度：3 个模块可同时开工，各自只需 Phase 1 模块提供编码查询**

### Phase 3：执行层 —— 串行依赖，集成枢纽

| 模块 | 依赖 | 核心任务 | 完成标志 |
|------|------|---------|---------|
| **mes** | plm, equip, wms, lims | 工单生命周期 + 工序流转 + 报工 + 追溯 | 能从蓝图创建工单并执行完整工序流转 |
| **aps** | mps, mes, equip | 排程建模 + 约束求解 + 甘特图 + 下发 | 能将 MPS 计划排到设备和时间段 |

> **关键词：mes 是整个系统的集成枢纽，必须先集中精力做好**

### Phase 4：响应层 —— 依赖 Phase 3 的运行时事件

| 模块 | 依赖 | 核心任务 | 完成标志 |
|------|------|---------|---------|
| **qms** | mes | 检验方案 + 检验记录 + 判定脚本 + 偏差/CAPA | 能在 MES 工序中触发检验并判定放行/拒收 |
| **andon** | mes, iot, qms | 异常呼叫 + 逐级上报 + 联动处理 | 设备故障时自动创建 Andon 呼叫并通知班组 |
| **eam** | equip | 维护工单 + 校准记录 + 备件管理 + 资产折旧 | 能从维护计划自动生成维护工单 |

> **并行度：qms 和 eam 可同时开工，andon 需要 qms 就先等 qms 完成判定逻辑**

### Phase 5：展示与聚合

| 模块 | 依赖 | 核心任务 | 完成标志 |
|------|------|---------|---------|
| **bi** | 全部 | 生产/质量/OEE/仓储看板 + KPI 聚合 | 生产看板实时刷新 |
| **web** | 全部 | Spring Boot 聚合 + REST API + 统一认证 | 能通过浏览器访问所有模块 API |
| **test** | 全部 | 跨模块集成测试 + 场景脚本 | 阿莫西林片剂全流程跑通 |

## 优先级说明

| 优先级 | 模块 | 理由 |
|--------|------|------|
| P0 | core | 已完成 — 一切的基础 |
| P1 | erp, plm, equip | 物料编码、工艺路线、设备台账——mes 的三个前置依赖 |
| P1 | wms | 没有仓储，MES 投料在真空中 |
| P1 | mes | 集成枢纽，整个系统的核心价值 |
| P2 | iot, lims, mps | IoT 数据采集、配方管理、生产计划——完善执行链路 |
| P2 | qms, andon | 质量管理和异常响应——制造系统的闭环关键 |
| P3 | aps, eam, dms, bi, scm | 高级排程、资产管理、文档管理、看板、供应链 |
| P4 | web, test | 统一门户和集成测试——所有模块完成后聚合 |
